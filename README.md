- Memory management, syscall interfaces, binary patching, and reverse engineering workflows
- Performance-aware engineering with a strong focus on system behavior and internals

### Offensive Security & Forensics

- Exploit research, vulnerability discovery, malware analysis, and controlled proof-of-concept work
- Incident response and investigative workflows grounded in network analysis and digital forensics
- Security-first thinking applied to infrastructure, tooling, and software delivery

### Infrastructure & Platform Engineering

- Secure environments built with **Docker**, **Kubernetes**, **VMware**, and enterprise device platforms
- Operational automation, system hardening, deterministic delivery, and resilient service design
- Experience across modern cloud, on-prem, and hybrid operational environments

### Languages & Automation

- Backend and automation work in **Go**, **Python**, **JavaScript**, **Java**, **PHP**, **Ruby**, and **Perl**
- Tooling and scripting for repeatable operations, service maintenance, and engineering efficiency
